String & File Handling

Olah teks, baca dan tulis berkas dengan konteks yang menutup berkas otomatis.

Buka Lab 3D

Konsep inti

String dapat diindeks dan dipotong, tetapi karakternya tidak dapat diganti langsung. strip() membuang spasi tepi dan split() memecah teks. with open(...) menutup berkas setelah blok selesai. Mode w menimpa isi lama; mode a menambah ke akhir.

Target praktik

Olah teks, baca dan tulis berkas dengan konteks yang menutup berkas otomatis.

Contoh: Simpan kode yang sudah dibersihkan

from tempfile import TemporaryDirectory
from pathlib import Path

kode = " b01 ".strip().upper()
with TemporaryDirectory() as folder:
    path = Path(folder) / "barang.txt"
    with path.open("w", encoding="utf-8") as f:
        f.write(kode + "\n")
    with path.open("r", encoding="utf-8") as f:
        print(f.read().strip())
