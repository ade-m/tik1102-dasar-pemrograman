Tujuan belajar

  • Mendefinisikan dan memanggil fungsi dengan def.
  • Membedakan parameter, argumen, return, dan print.
  • Menggabungkan beberapa fungsi untuk menyelesaikan satu kasus.

Dua fungsi, satu transaksi

def subtotal(harga, jumlah):
    return harga * jumlah

def total_bayar(nilai_subtotal, ongkir):
    return nilai_subtotal + ongkir

hasil = subtotal(15000, 3)
print(total_bayar(hasil, 5000))  # 50000

harga dan jumlah adalah parameter. Angka 15000 dan 3 adalah argumen. return memberikan hasil kepada pemanggil; print menampilkannya.

Dari inventaris ke kontrak fungsi

Gunakan dictionary dari Pertemuan 12. Fungsi pinjam menerima stok, kode, dan jumlah berupa bilangan bulat. Fungsi mengembalikan status. Stok berkurang hanya jika peminjaman berhasil; pada penolakan, stok tidak berubah.

def pinjam(stok, kode, jumlah):
    if kode not in stok:
        return "Kode tidak dikenal"
    if jumlah <= 0:
        return "Jumlah tidak valid"
    if jumlah > stok[kode]:
        return "Stok tidak cukup"
    stok[kode] -= jumlah
    return "Berhasil"

stok = {"B01": 5}
print(pinjam(stok, "B01", 2))  # Berhasil
print(stok["B01"])            # 3

Perhatikan efek samping: fungsi mengubah dictionary yang diterima. Variabel lokal berada di dalam fungsi, tetapi objek dictionary yang sama dapat terlihat berubah dari program utama.
