Fungsi

Pisahkan pekerjaan program menjadi bagian yang dapat dipanggil dan diuji kembali.

Buka lab interaktif

Tujuan belajar

  • Mendefinisikan dan memanggil fungsi dengan def.
  • Membedakan parameter, argumen, return, dan print.
  • Menggabungkan beberapa fungsi untuk menyelesaikan satu kasus.

Dua fungsi, satu transaksi

def subtotal(harga, jumlah):
    return harga * jumlah

def total_bayar(nilai_subtotal, ongkir):
    return nilai_subtotal + ongkir

hasil = subtotal(15000, 3)
print(total_bayar(hasil, 5000))  # 50000

harga dan jumlah adalah parameter. Angka 15000 dan 3 adalah argumen. return memberikan hasil kepada pemanggil; print menampilkannya.

Lab: telusuri panggilan fungsi

Ubah argumen dan lihat nilai yang dikembalikan tiap fungsi. Simulasi ini memodelkan contoh Python dengan JavaScript.

Hasil akan tampil di sini.

Latihan

Buat dua fungsi: satu menghitung luas persegi panjang, satu menghitung kelilingnya. Uji dengan panjang 10 dan lebar 5. Panggil kedua fungsi dari program utama.

Cek hasil yang diharapkan

Luas 50 satuan persegi, keliling 30 satuan. Gunakan return untuk kedua hasil dan tampilkan keduanya dari program utama.
