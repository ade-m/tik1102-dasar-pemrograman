Dictionary & Set

Kelola pasangan kunci–nilai dan olah kumpulan data unik.

Buka lab interaktif

Tujuan belajar

  • Membuat, membaca, memperbarui, dan menghapus entri dictionary.
  • Menghapus duplikasi dengan set dan membandingkan dua kelompok data.

Dictionary: akses berdasarkan kunci

stok = {"pensil": 8, "buku": 4}
stok["pensil"] = 10
stok["penghapus"] = 3
print(stok.get("spidol", 0))  # 0
for barang, jumlah in stok.items():
    print(barang, jumlah)
stok.pop("buku")

Gunakan keys() untuk kunci, values() untuk nilai, dan items() untuk pasangan keduanya. Akses stok["spidol"] akan gagal jika kuncinya belum ada.

Set: kumpulan elemen unik

A = {"apel", "jeruk"}
B = {"jeruk", "mangga"}
print(sorted(A | B))  # apel, jeruk, mangga
print(sorted(A & B))  # jeruk
print(sorted(A - B))  # apel

Gunakan set() untuk set kosong. {} membuat dictionary kosong. Di contoh ini, sorted() membuat urutan tampilan konsisten.

Lab: dua daftar, tiga operasi

Hasil akan tampil di sini.

Latihan

Buat dictionary barang dan stoknya. Ubah satu stok, tambahkan barang baru, lalu hitung daftar kategori unik dari beberapa barang.

Cek pemahaman

Jika A berisi apel dan jeruk, sementara B berisi jeruk dan mangga, selisih A - B hanya berisi apel. Selisih B - A hanya berisi mangga.

Studi kasus berlanjut: inventaris alat

Seperti pada materi masukan–proses–keluaran, tentukan dulu data yang dibutuhkan dan hasil yang diharapkan. Gunakan dictionary untuk stok per kode barang. Gunakan set untuk kategori unik atau membandingkan daftar barang dua ruang.

stok = {"B01": 5, "B02": 3}
kategori = {"alat tulis", "kertas"}
stok["B03"] = 4
kategori.add("alat tulis")  # tidak menambah elemen baru
print(stok.get("B03", 0))  # 4
print(len(kategori))      # 2
