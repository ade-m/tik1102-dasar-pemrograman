Buka Lab 3D

Konsep inti

def mendefinisikan fungsi. Tubuh fungsi dijalankan ketika dipanggil. Parameter menerima argumen dari pemanggil; return mengirim nilai kembali agar dapat dipakai dalam ekspresi lain.

Target praktik

Definisikan, panggil, dan gunakan hasil fungsi sederhana.

Contoh: Hitung subtotal

def subtotal(harga, jumlah):
    return harga * jumlah

hasil = subtotal(5000, 3)
print(hasil)
